How it works

The whole agent is one loop: ask the model, run whatever tools it requests, feed the results back, repeat until it answers in plain text.

response = client.chat.completions.create(

)

while response.choices[0].finish_reason == "tool_calls":
    msg = response.choices[0].message
    results = handle_tool_calls(msg.tool_calls)

    messages.append(assistant_turn(msg))  # what it asked for
    messages.extend(results)              # what happened

    response = client.chat.completions.create(
        model=MODEL_NAME, messages=messages, tools=tools
    )

return response.choices[0].message.content
01

Stateless by design

The full conversation is resent on every call. That is the entire "memory" of the app — refreshing the browser starts over.

02

History is cleaned first

Gradio 6 attaches metadata the API rejects, so each turn is rebuilt as {role, content} before it is sent.

03

Failure is a sentence

A dropped request, a bad tool call or an unknown tool returns a friendly reply instead of a stack trace in the chat window.

The tools

Tool calling is a contract in three pieces: a JSON schema, a Python function, and a lookup table that joins them by name.

ToolFires whenEffect
record_user_details A visitor offers an email or asks to be contacted Pushover notification with email and context
record_unknown_question The answer isn't in the profile Log the gap so the prompt can be improved
lookup_project Someone asks about a project, company or technology Keyword search over 8 curated projects, top 3 matches
get_contact_details Someone asks how to reach me Returns fixed links — never a guess, never paraphrased
record_conversation_rating A visitor rates the chat Validates 1–5, rejects the rest, notifies me
escalate_to_human Recruiter, contract offer, urgent request Mints an ESC-… ticket with urgency

Limits, stated plainly

This is a portfolio project, not a production SaaS.

No persistence

Leads, ratings and escalations live only in the notification. A durable store is the next step.

Keyword, not vectors

lookup_project scores word overlaps against 8 entries. It misses paraphrases an embedding index would catch.

Prompt injection is possible

A determined visitor can try to talk the twin out of character. Private details are kept out of the prompt.

Run it

Two commands and a free Gemini key.

git clone https://github.com/ahmedibrahimhassan654/ai-digital-twin.git
cd ai-digital-twin
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env      # add GOOGLE_API_KEY, PUSHOVER_USER, PUSHOVER_TOKEN
python app.py             # http://127.0.0.1:7860

python check.py --tools   # 6 tool checks, no API calls, nothing buzzes
python check.py           # + four real model conversations

Pushover keys are optional — without them the tools log instead of notifying.
